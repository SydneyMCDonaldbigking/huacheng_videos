# 画城环保 · 竖屏行业讲解视频（交接文档）

这个仓库只放做法：步骤、规则、分集脚本格式、检查清单和以往的经验。素材、配音、成片都不在这里，接手的设备按文档自己找、自己做。

成片是 1080×1920 竖屏、每集 45～60 秒的行业讲解片，发在画城环保的账号上。到 2026-11 已经做了三个系列共 24 集，见 [docs/07](docs/07_已做系列与经验.md)。

## 按顺序读

1. [01 流程](docs/01_流程.md)：从一篇文章到交付成片的七步，以及哪一步由谁做。
2. [02 规则](docs/02_规则.md)：品牌、内容、版权、配音、交付的硬性要求。
3. [03 分集脚本格式](docs/03_分集脚本格式.md)：每集一个 YAML，写清台词、镜头和信息卡片。
4. [04 模板说明](docs/04_模板说明.md)：渲染模板做了什么、成片规格、画面样式。
5. [05 找素材](docs/05_找素材.md)：Pexels / Pixabay 怎么搜、怎么下、怎么筛。
6. [06 检查与交付](docs/06_检查与交付.md)：出片前后的检查项、交付文件夹的结构。
7. [07 已做系列与经验](docs/07_已做系列与经验.md)：做过的 24 集、还没了结的事、踩过的坑。

## 接手后先做

1. 向用户要：这一批的文章或资料、男20号参考音（或者已经配好的配音）。
2. 建 Python 环境：用 conda 或 venv，**不要全局 `pip install`**。Windows 上运行 Python 加 `-X utf8`，临时目录指到空间大的盘。
3. 读 01 和 02，然后从 01 的第一步开始。
