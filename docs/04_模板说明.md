# 04 模板说明

模板在本仓库的 [`templates/explainer/`](../templates/explainer/README.md)，2026-11-09 按这一页重建。以前的模板放在 `Opue_video_add` 的工作目录里，从来没有提交过，已经丢了；现在的模板不依赖那个私有仓库的渲染引擎。命令、文件和重建时自己定的参数见模板的 README，这一页记成片该是什么样。

## 结构

- `build.py`：读分集 YAML 和配音，算时间轴，生成两个工程 `build/<名字>/full/project.yaml`（完整版）和 `clean/project.yaml`（无字幕版），同时写出 `subs.srt`、`timing.json`、`voice.wav`、`mix.wav`、`voice_clean.wav`、`music_stem.wav`。
- `template.py`：素材预处理：裁成竖屏、取片段、统一 30 fps。压暗和模糊在渲染时只加在完整版上。
- `overlay.js`：所有卡片、字幕、角标、片尾卡的画法和动画。
- `render.py`：渲染。`--preview` 出 540×960 预览，正式渲染出成片；两种都附一张联系表 `out/<名字>.sheet.jpg`。
- `check.py`、`deliver.py`：第 6、7 步的检查和交付。

工程 `project.yaml` 由 `build.py` 生成，不要手改。完整版的开头大致是这样：

```yaml
template: explainer
name: jz5
title: 用了再生料出问题，谁担责？
canvas: {w: 1080, h: 1920, fps: 30}
frames: 1380                # 总帧数，两个版本一样
look: {vignette: 0.1, grain: 1.4, fade_out: 0.6}
version: full               # 或 clean
audio: ../mix.wav           # 无字幕版是 ../voice_clean.wav
shots:                      # id, t0, f0（起始帧）, frames, clip {path, in, x, px}, dim, blur；最后一个 id 是 end
assets: {logo: <logo_icon.png 的路径>}
corp: {name: 画城环保, tagline: 产业治废 · 美画城市, company: 成都画城环保科技有限公司, site: huacheng.city, series: 建筑垃圾资源化 · 行业观察 05}
end: {t0: 41.2, t1: 46.0, next: 正规工厂，为什么无米下锅？}
caps:                       # 一屏一条：t0, t1, text, keys
cards:                      # 锚点已换算成秒
```

画城图标 `templates/explainer/assets/logo_icon.png` 是从官网的 logo（[huacheng-logo-full.png](https://www.huacheng.city/huacheng_assets/huacheng-logo-full.png)，存为 `assets/huacheng_logo_full.png`）用 `make_logo.py` 抠出来的透明底图标。

## 成片规格

| 项目 | 要求 |
|---|---|
| 画面 | 1080×1920，30 fps，H.264 |
| 色彩标记 | BT.709，tv range（limited） |
| 音频 | AAC，48 kHz，立体声 |
| 响度 | 完整版约 −15 LUFS，真峰值约 −1.5 dBTP |
| 时长 | 45～60 秒（以往是 45～82 秒） |
| 画面质感 | 轻暗角 0.1，颗粒 1.4，结尾 0.6 秒淡出 |
| 完整版和无字幕版 | 帧数必须一样 |

## 时间轴

1. 片头 `lead`（2.4 秒）只有标题卡和第一个镜头，没有配音。
2. 每句的长度 = 那句 WAV 的长度，句与句之间隔 `pause` 秒（默认 0.4）。
3. 最后一句和它的 `pause` 之后接 `end_card` 秒（5 秒）的片尾品牌卡。
4. 时长由配音决定。配音短了就靠片头、停顿、片尾补，**不拉伸配音**。

`timing.json` 的 `lines` 记下每句的起止秒数，比如 `"JZ05_01": [2.4, 6.632]`；另外有片尾卡的起止、总时长、总帧数、混音的增益和响度，以及构建时的提醒（片长不在 45～60 秒、镜头太长太短、素材不够长、卡片重叠、`note` 撞上片头标题卡）。

## 字幕

- 每句按标点（，、。？；：）拆成几屏，太短的小句合并，一屏最多约 14 个字。每屏的时长按字数在这句里分配。
- 字幕在画面下方居中，白色粗体，带深色描边或阴影。
- `keys` 里的词显示成绿色。
- SRT 也按屏输出，内容照 `cap` 原文。比如字幕是「PPT」，即使配音念的是「P、P、T」，SRT 里也写「PPT」。

## 画面样式

从成片里取的颜色，重建时以已交付的成片为准：

- 强调色（亮绿）：约 `#3CD764`。用在 `*高亮*` 文字、圆点、节点、标签边框上。
- 卡片底色：深墨绿，约 `#0E1C12`，半透明，圆角，有细的绿色描边。
- 问题色：`bad: true` 和 `tone: waste` 用红色系。
- 中文字体用粗黑体，比如思源黑体 Bold 或 Heavy。

各部分：

- **左上角角标**：画城图标 + 「画城环保」+ 一行灰色小字系列名，全片都在。片头标题卡出现时不显示。
- **hook 标题卡**：上面一个绿色小标签（kicker），下面是三行左右的大白字，高亮部分是绿色，再下面一条绿色短线和小字「行业观察」。
- **tag**：带绿色圆点的深色小条，下面可以有一行灰色小字。
- **points**：标题一行，下面每条是深色圆角条，左边带圆形编号，按 `at` 的时刻依次点亮。
- **cycle**：圆形路径上排几个节点，节点依次点亮，中心两行字。
- **note**：底部一行灰色小字（`y: 1262`），在字幕上面。
- **片尾卡**：背景是 `end` 镜头压暗，中间一个大图标，下面「画城环保」大字、口号、公司全称、网址，最下面一个「下集预告」框写下一集标题。

## 音频

- 配乐来自 Pixabay，从 `music.start` 秒开始截取。
- 片头没有人声时配乐在 `open_db`（−9 dB），有人声时压到 `duck_db`（−20 dB），过渡平滑。片尾卡时再抬起来。
- 人声和配乐混好后整体做响度标准化，目标 −15 LUFS。
- `music_stem.wav` 是已经做好避让的配乐单独导出，单独交付。

## 无字幕版

同一条时间轴，只保留镜头画面和配音：

- 不要字幕、卡片、角标、片尾卡；
- 不要配乐；
- 去掉 `dim` 和 `blur`，那是为了衬卡片才加的；
- 片尾那 5 秒只放 `end` 镜头的原画面。

## 素材预处理

- 横屏素材裁成 9:16，裁切框的水平中心是 `clip.x`（默认 0.5）。竖屏素材直接缩放。
- 素材的帧率（24/25/30/60/100）统一转成 30 fps。
- 下载 1920×1080 的版本就够用。4K 只用在需要放大裁切的镜头上。
