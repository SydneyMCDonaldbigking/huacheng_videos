# 05 找素材

## 去哪找

- **视频：** Pexels（Pexels License，可免费商用，不要求署名）为主，Pixabay 补充。
- **音乐：** Pixabay Music。只选不是 AI 生成、也没有 Content ID 的，免得发布后被平台认领。以往用过的几首，按文件名：
  - `499582_technology_bombinsound`
  - `520384_presentation_prettyjohn1`
  - `571900_business_sub_clair`
  - `605770_uplifting_friend_easy_eva`

## 用浏览器搜 Pexels

Pexels 的 API 需要密钥。以往的做法是在浏览器里打开 pexels.com，然后在页面里运行脚本，取搜索结果页的数据：

```js
const html = await (await fetch('/search/videos/' + encodeURIComponent('construction waste') + '/')).text();
const data = JSON.parse(new DOMParser().parseFromString(html, 'text/html')
  .querySelector('#__NEXT_DATA__').textContent);
const rows = data.props.pageProps.initialData.data.map(d => d.attributes);
// 每条有：id, width, height, duration, fps, title, license, user, video.video_files（各分辨率的文件）
```

- 用英文关键词搜，每个关键词都换几种说法，比如 demolition、excavator debris、rock crusher、gravel conveyor、road roller、concrete crack、dump truck。
- 搜结果里能看到作者、标题、时长、帧率、分辨率，以及每个分辨率的文件路径。

## 下载前先看预览

- 老一些的素材有 15 张预览帧：`https://images.pexels.com/videos/<id>/pictures/preview-<0..14>.jpg`。拼成一张联系表，一眼就能看完一段素材。
- 新一些的素材只有一张缩略图：`https://images.pexels.com/videos/<id>/pexels-photo-<id>.jpeg?auto=compress&cs=tinysrgb&w=400`。
- 看预览时要排除：
  - 品牌和 logo；
  - 车牌、文字招牌；
  - 地标建筑；
  - 长时间不动的画面；
  - 和主题无关的内容。

## 素材清单格式

以往把要下载的素材记成一行一条：

```
编号|宽x高|时长|帧率|作者|标题|1080p 文件路径|4K 文件路径
34241190|3840x2160|45|60|RAJU THAPA|Powerful Demolition of Urban Structure|34241190/14511141_1920_1080_60fps.mp4|34241190/14511143_3840_2160_60fps.mp4
```

- 文件路径前面加 `https://videos.pexels.com/video-files/` 就是下载地址，存成 `footage/<编号>.mp4`。
- 这份清单同时用来写交付里的 `素材来源.md`。

## 下载后再看一遍

预览帧有时漏掉东西，下载后要在**裁成竖屏之后**的画面上再查一次品牌和文字。查的方法：

- 按每 0.5～1 秒抽帧，拼成联系表看；
- 有可疑的地方，再按 0.1 秒抽帧细看。
