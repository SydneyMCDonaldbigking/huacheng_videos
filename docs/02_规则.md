# 02 规则

这些规则都是用户提出或确认过的，交付前逐条对照。

## 品牌

- 账号是「画城环保」。片子里的公司信息固定写成：
  - 名称：画城环保
  - 口号：产业治废 · 美画城市
  - 公司：成都画城环保科技有限公司
  - 网址：huacheng.city
- 左上角一直挂角标：画城图标 + 「画城环保」+ 一行小字系列名（比如「建筑垃圾资源化 · 行业观察 05」）。
- 片尾是品牌卡：大图标、画城环保、口号、公司全称、网址，下面一个「下集预告」框写下一集标题。最后一集没有预告。

## 内容

- **只讲资料里有的内容。** 不加资料里没有的数字、政策名、机构名。要用的数据必须能核实，并在画面上用小字注明来源。以往的例子：文章把全国硫酸产能写成 8000 万吨，核实后改用中国硫酸工业协会的 2024 年数据 1.406 亿吨，并注明来源。
- **资料不是画城自己的，就不写成画城在做。** 这类系列定位为「行业观察」或「行业方案」，讲行业现状，不宣称画城有这项技术。
- **画城自己的技术只用画城资料里的说法。** 资料是一份 PDF：《副产石膏硫钙资源高值化利用新技术》，向用户要。不要把 PDF 截图放进视频。
- 不写别家公司和产品的品牌，不点名批评任何公司。案例只写省份，比如「四川」「山东」。
- 数字没达到客户要求，就不写「达标」。
- 话题涉及监管、政府、责任划分时，画面底部加一行小字「行业观点，仅供参考」。用到案例数据时写「案例数据来自行业公开资料」，用到测算数据时写「以上为测算数据，实际收益以项目条件为准」。

## 版权

- 视频素材只用 **Pexels** 和 **Pixabay** 上可免费商用的。
- 音乐用 **Pixabay**，只选不是 AI 生成、也没有登记 Content ID 的。
- 画面里不能出现：
  - 看得清的品牌和 logo，比如工程机械上的 HITACHI、CAT、CASE、TOYOTA；
  - 车牌、看得清的文字招牌、外文标语；
  - 有名的地标建筑；
  - 战争、地震的废墟。搜 rubble 时这类画面很多。
- 每批交付附一份 `素材来源.md`，列出用到的每个素材：编号、作者、标题、链接。

## 配音

- 声音用「男20号」，语气用「B_讲解语气」，由用户在外部 AI 上克隆生成。一套片子不要混用两种语气。
- 成片不用本地 TTS。
- 读音和用词只能由用户确认，接手的人只做机械检查和语音识别对稿。

## 交付

每集交四个文件：

1. **完整版**：画面 + 配音 + 字幕 + 信息卡片 + 角标 + 片尾卡 + 配乐。
2. **无字幕版**：同一条时间轴，只有画面和配音。没有字幕、卡片、角标、片尾卡，也没有配乐。为了衬卡片而做的压暗和模糊也要去掉。这个版本给运营的同事自己加字幕。
3. **SRT 字幕**：配音的时间轴字幕。
4. **配乐**：单独的音频文件，已按配音做好避让。

整批再加 `发布文案.md` 和 `素材来源.md`，格式见 [06](06_检查与交付.md)。

## 环境

- Python 用 conda 或 venv，**不要全局 `pip install`**。
- Windows 上运行 Python 加 `-X utf8`，否则中文路径和中文字幕会出问题。
- C 盘空间小，素材、工程、临时文件（`TMP`/`TEMP`）都放到大盘上。
