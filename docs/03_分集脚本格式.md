# 03 分集脚本格式

每集一个 YAML 文件，比如 `episodes/jz5.yaml`。构建程序读它，加上配音文件，生成工程。**要改片子就改这个文件**，不要直接改生成出来的工程。

## 完整例子：建筑垃圾第 5 集


## 时间锚点

`at`、`from`、`to` 都用锚点表示时间，有四种写法：

| 写法 | 意思 |
|---|---|
| `0` | 片头开始，也就是第 0 秒 |
| `JZ05_02` | 这句开始的时刻。用在 `to` 上表示这句结束的时刻 |
| `[JZ05_02, 0.5]` | 这句念到一半的时刻。第二个数是这句**时长的比例** |
| `"JZ05_02+1.2"` | 这句结束后再过 1.2 秒 |

**容易犯的错：** `to: [JZ05_02, 1.4]` 是这句时长的 1.4 倍，不是秒。要表示「这句结束后再停 1.2 秒」，写 `"JZ05_02+1.2"`。

## lines：台词

| 字段 | 意思 |
|---|---|
| `id` | 句子编号，同时也是配音的文件名 |
| `cap` | 字幕，照原稿写。按标点自动拆成几屏 |
| `keys` | 字幕里要高亮成绿色的词 |
| `pause` | 这句之后停多少秒，默认 0.4。段落之间用 0.6～0.7 |
| `say` | 只在用本地 TTS 时用：念法和字幕不同的时候写（比如用同音字纠正多音字）。用外部配音时，念法写在 `lines.json` 里 |

时间轴由配音决定：片头 `lead` 秒之后接第一句，每句的长度等于它那个 WAV 的长度，句与句之间隔 `pause` 秒。

## shots：镜头

| 字段 | 意思 |
|---|---|
| `at` | 从哪个时刻开始切到这个镜头，一直用到下一个镜头开始 |
| `clip.px` | Pexels 视频编号 |
| `clip.in` | 从素材的第几秒开始用 |
| `clip.x` | 横屏素材裁成竖屏时，裁切框的水平中心（0～1，默认 0.5）。画面某一侧有文字或品牌时用它避开，比如 `x: 0.72` |
| `dim` | 压暗，0～1。镜头上要叠卡片时用，常用 0.42～0.45 |
| `blur` | 模糊半径，常用 3～4，和 `dim` 一起用 |
| `end` | 片尾品牌卡下面的背景镜头，会自动压暗 |

每个镜头 2.5～8 秒。镜头太长就在一句中间换，比如 `[JZ05_02, 0.5]`。

## cards：信息卡片

所有卡片都有 `kind`、`from`、`to`、`y`（卡片顶部的纵坐标，画布高 1920）。文字里用 `*星号*` 包起来的部分显示成绿色，`\n` 换行。

| kind | 用途 | 主要字段 |
|---|---|---|
| `hook` | 片头大标题，`from: 0` | `kicker`（标题上方的小标签）、`title`、`line`（标题下方小字，比如「行业观察」） |
| `tag` | 一句话标签 | `text`、`sub`（下方小字） |
| `points` | 要点列表，逐条出现 | `title`、`items: [{num, text, sub, at}]`、`rowH`（行高）、`bad: true`（用红色表示问题） |
| `flow` | 流程图 | `title`、`h`、`nodes: [{id, text, x, y, tone, at}]`、`edges: [[from, to, "标注"]]`；`tone` 可选 `in`（来源）、`waste`（问题）、`prod`（产出） |
| `compare` | 左右对比 | `left: {title, items}`、`right: {title, items}`、`at`（各行出现的时刻）、`rowH` |
| `cycle` | 一圈节点 + 中心字 | `items`、`center`、`r`（半径） |
| `stat` | 一个大数字，会从 0 往上数 | `label`、`value`、`suffix`、`sub` |
| `stats` | 几个大数字 | `title`、`items: [{value, suffix, label, sub, at, count: false}]`、`rowH` |
| `bars` | 横向柱状对比 | `title`、`series: [{label, a, b, hi, at}]`、`la`/`lb`（两组的名字）、`legend` |
| `quad` | 四宫格 | `items: [{label, value, prefix, suffix, sub, at}]`、`ch`（格高）、`allOn` |
| `route` | 一条技术路线的说明 | `idx`、`name`、`cap`、`items: [{k, v}]`、`invest` |
| `eq` | 化学方程式 | `title`、`step`、`eq`、`hi`（要高亮的物质）、`note`、`size` |
| `note` | 底部一行小字，用来写来源或免责 | `text`，`y` 固定 1262 |

几种卡片的写法示例（数字是示意）：

```yaml

- {kind: stats, from: c6, to: c6, y: 520, rowH: 230,
   items: [{value: 95, suffix: "%+", label: "指标一", sub: "说明", at: [c6, 0.2]},
           {value: "3–6", suffix: "个月", count: false, label: "指标二", at: [c6, 0.55]}]}
- {kind: bars, from: j4, to: "j4+0.7", title: "产能对比（万吨/年）", y: 420, rowH: 210, legend: false,
   series: [{label: "全国总量", a: 14060, dec: 0, at: [j4, 0.6]}, {label: "其中某一类", a: 800, dec: 0, hi: true, at: [j4, 0.2]}]}
- {kind: flow, from: JZ06_03, to: "JZ06_03+0.5", title: "料去了*哪里*", y: 380, h: 760,
```

## 排版经验

- `hook` 从 0 一直放到第一句的 25% 左右，`y: 700`。
- `tag` 放在 `y: 400`；列表、流程、对比放在 `y: 380～430`；`cycle` 的圆心在 `y: 800`。
- 字幕在下方。卡片的下沿不能压到字幕，也不能压住画面里的人脸。
- `note` 不要和 `hook` 同时出现：`note` 从第一句的 25%～30% 开始。
- 同一时刻最多一张主卡片。前后两张卡片不要重叠，构建前把各卡片的时间排一遍。
- 卡片底下的镜头要加 `dim` 和 `blur`，不然字看不清。
